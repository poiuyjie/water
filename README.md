# water — 水下 3D Gaussian Splatting 建图系统 · Time-to-Map

> 研究主线：**在保证地图质量的前提下，最小化"从水下视频到可用 3DGS 地图"的时间。**
> 免离线 COLMAP，在浑水中边采集边建图，并给出免 GT 的米制尺度。

![位姿光度一致性决定渲染质量](docs/assets/filmstrip_slam_vs_hq.jpg)

左：SLAM 位姿图位姿直接喂 3DGS（概览级）；右：光度一致位姿 + 双输出联合 init（高质量配方）。
局部逐对光度一致性是水下 3DGS 渲染质量的主导因素（E2026-0921-13..16 真值重跑定论）。

## 核心结果（canonical 冻结口径 · 2026-09-24）

| # | 结果 | 数字 | 证据 |
|---|------|------|------|
| ① | **Time-to-Map** | T@0.15 = **698 s**（170 帧，含推理与评测，独占 GPU 计时） | E2026-0924-07 |
| ② | **预算响应阶梯** | 锐度 retention **0.038 → 0.243 → 0.337**（6.8k / 20.4k / 40.8k iters） | E2026-0924-07 |
| ③ | **同 init 离线上限** | batch REF = **0.426**；增量结构锐度税 ≈0.06，事后不可恢复 | E2026-0924-07/08 |
| ④ | **D-conf 导引压缩** | 高斯 **−20.4%** · 渲染 FPS **+15.3%**（208→240 同卡实测）· VRAM −7.5%，质量持平 | E2026-0924-08/09 |
| ⑤ | **GT-free 米制化** | AQUALOC SE3-ATE **1.676 → 0.578 m（−65.5%）**，全局单参数定标 | E2026-0921-18 |

**正式措辞（引用请逐字）**：

> 在 DIRECT D-init + 在线位姿 + 增量 3DGS 条件下，系统地测得优化预算是早期地图质量的
> 一阶因素；位姿质量在预算提升后成为进一步限制因素；若干直觉上的
> depth/fusion/densification 调整未显示同量级收益。

不声称"解决了水下 3DGS 核心难点"。诚实边界见[报告页结论](https://poiuyjie.github.io/water/#conclusion)。

## 方法一览

水下视频帧 → DIRECT 双输出推理（**D** 单目深度 + **J** 去浊外观）→
D 逐帧米制定标反投影为初始化点 → 增量光度训练（官方 densify/prune 调度）→
质量门控评测（PSNR + 锐度 retention）。实证角色分工：
**D = 几何初始化桥 + 表示压缩调度器 + 米制源；J = 外观紧凑化。**

## 边界（诚实条目）

- 主结论在 coral 浑水序列（170 帧，单场景）；AQUALOC（441 帧）复现预算-响应趋势，
  完整 canonical 未重跑。
- 在线建图为 near-online（170 帧约 15 分钟），非 real-time。
- 增量 → batch 存在 ~0.06 结构性锐度税，本页如实呈现差距而非回避。
